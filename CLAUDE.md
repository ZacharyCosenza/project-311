# CLAUDE.md

## Comments

Don't add comments that restate what the code already says. Only comment when there's a
genuine "why" that isn't obvious from reading the code itself — a gotcha, a non-obvious
business rule, a reason a simpler approach doesn't work. When editing existing code,
don't leave behind comments narrating the edit itself ("now handles X", "added Y for Z")
— that belongs in the commit message, not the file.

If in doubt, leave it out.
